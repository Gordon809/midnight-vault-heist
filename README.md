Midnight Vault Job — a top-down stealth heist game: slip through a guarded gallery, dodge guard vision cones and sweeping security cameras, steal 3 of 5 treasures, and vanish through the service door before the alarm hits 100%.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or arrow keys, hold Shift to sneak, click the floor to toss a coin and lure a guard, click loot up close to grab it, and press E for a one-time camera EMP.
